# Kanekist Replay

Нативный рекордер для Windows 10/11: аппаратная запись рабочего стола,
Instant Replay, PNG-скриншоты, глобальные горячие клавиши, захват системного
звука/микрофона, FPS-индикатор и локальная библиотека медиа.

## Требования

- Windows 10 1903 или новее, x64
- Visual Studio 2022 с workload **Desktop development with C++**
- CMake 3.24+
- GPU и драйвер с Media Foundation H.264 encoder (NVIDIA, AMD или Intel)

## Сборка

Откройте **Developer PowerShell for VS 2022**:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
.\build\Release\KanekistReplay.exe
```

Настройки, журнал и временный replay-файл находятся в
`%LocalAppData%\KanekistReplay`; клипы и скриншоты — в подпапке `Media`.

## Горячие клавиши

- `Alt+K` — открыть/закрыть игровое Kanekist Overlay (хоткей можно сменить)
- `Ctrl+Shift+R` — начать/остановить запись
- `Ctrl+Shift+S` — сохранить Instant Replay
- `Ctrl+Shift+P` — сделать скриншот
- `Ctrl+Shift+O` — показать/скрыть FPS overlay

Все пять сочетаний назначаются в главном окне: нажмите кнопку хоткея и новое сочетание.

## Реализованный pipeline

- DXGI Desktop Duplication выдаёт кадры как `ID3D11Texture2D`.
- Перед Media Foundation кадр переводится в непрерывный BGRA-буфер. Это
  гарантирует совместимость со встроенными H.264 MFT на NVIDIA, AMD и Intel
  и исправляет MP4, в которых раньше создавалась только аудиодорожка.
- Профиль «Максимум» использует H.264 High Profile и 45–60 Мбит/с, «Ультра»
  — до 120 FPS и 70 Мбит/с. Частота подачи кадров ограничена выбранным
  профилем, поэтому монитор 240 Гц не заставляет кодировать лишние кадры.
- WASAPI event-driven loopback и capture работают на MMCSS audio thread;
  системный звук кодируется в AAC и синхронизируется с видео по QPC clock.
- Запись ограничивает работу одним кадром за событие Desktop Duplication;
  ошибки/пропуски считаются и не создают неограниченную очередь.
- Скриншот использует staging texture только в момент сохранения.
- В комплект включён Intel PresentMon 2.5.1 (MIT): он измеряет FPS активной
  игры через ETW без DLL injection. При недоступном ETW интерфейс явно
  переключается на показатель FPS захвата.
- PresentMon запускается один раз на весь сеанс; настройки HUD глобальны для
  всех игр. В Alt+K циклически настраиваются угол, цвет, толщина обводки,
  шаблон (`FPS`, `1% low`, frametime, CPU/GPU) и длительность Replay.
- FPS HUD рисуется без фоновой панели: DirectWrite + попиксельная прозрачность.
  Шрифт по умолчанию — Bahnschrift. Обводка циклически меняется в Alt+K;
  при толщине 0 остаётся лёгкая тень, без «рваных» краёв color-key.
- Все настройки (качество, HUD, микрофон, Replay, шрифт, папка медиа)
  сразу пишутся в `%LocalAppData%\KanekistReplay\settings.json`.
- Интерактивное меню `Alt+K` — полупрозрачная стеклянная панель Direct2D
  поверх borderless/windowed-игры: запись, Instant Replay, скриншот,
  галерея, микрофон, FPS HUD, качество, позиция/цвет/обводка/текст/шрифт
  HUD и длительность Replay, плюс FPS/1% low/frametime/CPU/GPU busy.
- Запись сначала идёт в `*.partial.mp4`, затем атомарно публикуется после
  `Finalize`; завершение выполняется в фоне, не замораживая интерфейс.
- Instant Replay хранит текущую сессию 1–30 минут (в меню — минуты, не секунды)
  и по нажатию в фоне обрезает буфер через bundled LGPL FFmpeg без перекодирования.
- Громкость игры и микрофона, а также шумодав микрофона, настраиваются слайдерами
  и сразу сохраняются.
- Перед записью и включением Replay показывается предупреждение, если на диске
  мало места; в статусе виден свободный объём и оценка в минутах.
- Закрытие и сворачивание уводят программу в трей; выход — из меню иконки.
  Опция «Стартовать в трее» запускает рекордер свёрнутым.
- Системный звук и микрофон приводятся к float stereo 48 kHz, смешиваются с
  limiter и записываются в одну AAC-дорожку, слышимую в обычном проигрывателе.

## Ограничения первой версии

- Захватывается основной монитор. Выбор отдельного окна и нескольких мониторов
  подготовлен архитектурно, но ещё не подключён к UI.
- FPS HUD один на весь основной монитор: сетка 3×3 (включая центр, выше и ниже)
  и отдельный размер текста. Не прыгает за каждым окном.
- Instant Replay сохраняет текущий непрерывный временный MP4 и сразу начинает
  новый. Кольцевой буфер закодированных сэмплов реализован и протестирован, но
  Media Foundation Sink Writer не предоставляет encoded output для его прямого
  подключения без собственного MFT/muxer.
- Exclusive fullscreen и DLL injection намеренно не поддерживаются. Используйте
  borderless/windowed режим.

Проект не внедряется в игры, не требует прав администратора и не отправляет
телеметрию.
